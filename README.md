# BMTC-Route-Intelligence
An end-to-end ML and data analytics pipeline on Bangalore's public transport network.

## What it does
Analyzes 4,271 BMTC routes using clustering, anomaly detection, and network analysis to identify inefficiencies and underserved areas across Bangalore.

## Tech Stack
Python, Pandas, Scikit-learn, HTML, CSS, JavaScript

## Features
- K-Means clustering and Isolation Forest anomaly detection
- PageRank network analysis identifying critical transit hubs
- Interactive dashboard visualizing 798 underserved stops
